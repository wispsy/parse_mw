# Changelog

## 0.1.0 (2026-11-22)

- Add a bounded, source-preserving MediaWiki parser with immutable nodes and
  source spans.
- Add fragments, documents, sections, parsing and typed HTML rendering APIs.
- Support headings, lists, tables, bold/italics, code/pre/math, templates,
  comments, entities, tags, references, categories and MediaWiki links.
- Preserve MIT licensing and provide exact distribution qualification.
